 Question 1/1: Build loop

 The release build fails on its second step, after the cache is restored. This is the part of
 scripts/build.sh that runs there:

     for f in src/*.py; do
         python3 -m py_compile "$f" || exit 1
     done
     make -C build test JOBS=4

 The same check could run as one call instead:

     import compileall, sys
     ok = compileall.compile_dir("src", quiet=1)
     if not ok:
         sys.exit(1)

 Each file is compiled on its own today, so one bad file stops the loop before the tests run. The
 single call reports every bad file at once.

 Should I keep the loop as it is, or replace it with one compileall call?

 ❯ 1. Keep the loop
      Leave scripts/build.sh as it is; the first bad file stops the build.
   2. Use compileall
